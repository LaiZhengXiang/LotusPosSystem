# Lotus POS System 
A point-of-sale system developed in C++ for my Software System Development coursework.

## Overview
This project simulates a retail checkout system. It allows users to input items, calculate totals with tax, and manage basic inventory.

## Features
* **User Authentication:** Secure login for staff.
* **Dynamic Billing:** Calculates subtotal and GST.
* **Inventory Management:** Track stock levels for products.
* **Receipt Generation:** Prints a summary of the transaction to the console.

## How to Run
1.  Clone this repository.
2.  Open the `.cpp` file in an IDE (like Dev-C++ or Visual Studio).
3.  Compile and Run the program.
